# Flexbox Layout Homework

This project is a replication of the provided layout image using HTML and CSS Flexbox. 

## Approach & Notes

- I used **padding** and **margin** properties to preserve the structure and spacing between the rectangles, as I couldn't find another way to achieve the exact look while maintaining the layout.
- The `.container` uses `min-height: 100vh` to ensure the rectangles fill the entire screen. Without this, each component would shrink due to the lack of content inside them.
- The color-coded borders are for visual clarity and to match the provided image.

## Structure
- The layout consists of a header, navbar, content area, and a footer with two sections, all arranged using Flexbox.

Feel free to explore the code in the `src/app/layout/` folder for the HTML and CSS implementation.
